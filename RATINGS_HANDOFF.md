# Handoff: Fix player ratings for the /perfect-cup/ World Cup XI draft

## Goal

Replace/improve the player **ratings** powering the GAFFA "Name Your Side" draft
game at `ballknw.com/perfect-cup/`. The current ratings are inconsistent —
modern years use real EA Sports FIFA numbers, but historical (pre-2000) years are
synthetic estimates, and ~22% of players carry placeholder attribute stats. We
want a better/more consistent ratings database across all eras.

## Where the data lives (exact paths)

| File | Role |
|------|------|
| `data/players.json` | **Source of truth.** 8,273 players, 344 national squads, 1930–2026. This is what needs improving. |
| `gaffa/scripts/build-squads.mjs` | Build script. Reads `../../data/players.json`, groups by `country\|year`, writes `gaffa/public/data/squads.json`. |
| `gaffa/public/data/squads.json` | **Generated** — do not hand-edit. Regenerated by the build script. |
| `gaffa/lib/draft-data.ts` | Types (`Player`, `ClubSeason`) + position logic (`SLOT_ACCEPTS`, `playerFillsSlot`). |
| `perfect-cup/**` | **Committed static export** that actually ships (Netlify publishes the repo root). Regenerated from `gaffa/out/`. |
| `draftfantasy/public/data/players.json` | A *second copy* used by the orphaned draftfantasy app. Not used by GAFFA — ignore unless you want to keep them in sync. |

## Source record shape (`data/players.json`)

```jsonc
{
  "meta": { "years": [1930, ...], "total_players": 8273,
            "attribution": "...ratings: derived from tournament performance and
                            position baselines for historical years, EA Sports
                            FIFA for modern years." },
  "players": [
    {
      "n": "Lionel Messi", "country": "Argentina", "year": 2022,
      "p": ["FW"],                      // generic line: GK/DF/MF/FW
      "pac":85,"sho":89,"pas":90,"dri":94,"def":34,"phy":64,  // FIFA attributes
      "o": 90,                          // OVERALL — the ONLY rating the game uses
      "sp": "CF",                       // specific position (drives slot eligibility)
      "sp2": ["CF","CAM","RW"]          // alternate positions
    }
  ]
}
```

- **`o` (overall) is the rating.** `build-squads.mjs` copies `o` → both `rating`
  and `peak` in `squads.json`. The six FIFA attributes (`pac`…`phy`) are **not
  currently read by the game** — only `o` matters for gameplay/sim today.
- `sp` / `sp2` drive position eligibility — **preserve these** when replacing data,
  or the draft's position filtering breaks.

## The problem, quantified (measured on current `data/players.json`)

- Overall (`o`) range: **20 – 91**, median **65**.
- **1,841 / 8,273 players (22.3%) have all six attributes = 99** (placeholder).
  Concentrated in historical decades:
  - 1930s: 306/323 · 1950s: 241/615 · 1960s: 209/270 · 1970s: 411/434 ·
    1980s: 168/176 · 2010s: 506/2857 · **2000s & 2020s: 0 junk** (real FIFA).
- Modern top overalls look right (Messi 90, Mbappé 87, Kane 86 for 2022);
  historical overalls are flat/synthetic (France 1930 clustered at 69–70).

**Interpretation:** the fix is a better *source* for historical-era ratings (and
optionally real per-attribute stats), normalized to the same scale as the modern
EA-derived years. The game only needs `o` to be good; attributes are optional
polish unless you later surface them in the UI.

## How to apply a fix (full regenerate → redeploy pipeline)

```bash
# 1. Edit / replace the source ratings
#    -> data/players.json  (keep the {meta, players:[...]} shape, keep n/country/
#       year/p/o/sp/sp2 fields intact)

# 2. Regenerate the squad dataset the game reads
cd gaffa
pnpm install                       # first time only
pnpm build:squads                  # -> gaffa/public/data/squads.json

# 3. Rebuild the static export under the /perfect-cup basePath
NEXT_PUBLIC_BASE_PATH=/perfect-cup pnpm build     # -> gaffa/out/

# 4. Swap the committed export that actually ships
cd ..
git rm -r perfect-cup
cp -a gaffa/out/. perfect-cup/
touch perfect-cup/.nojekyll        # Next export doesn't emit this; keep it

# 5. Commit + push + open PR into the deploy branch (claude/build-vnqqbp)
git add -A && git commit -m "Improve player ratings database"
git push -u origin <your-branch>
```

Netlify publishes the repo root, so once the PR merges to `claude/build-vnqqbp`
the new ratings ship at `ballknw.com/perfect-cup/`.

## Constraints / gotchas

- **Don't hand-edit `gaffa/public/data/squads.json` or `perfect-cup/`** — both are
  generated. Always change `data/players.json` then re-run the pipeline.
- **Preserve `sp`/`sp2`** (specific positions). The draft only enables a player for
  a slot if their position fits (`playerFillsSlot` in `gaffa/lib/draft-data.ts`).
- Ratings should stay on a **0–100 overall scale** and be internally consistent
  across eras (the sim in `gaffa/lib/sim.ts` compares `rating` directly, with an
  `opp_baseline` of ~72 in `meta`).
- The game does **not** currently use the six FIFA attributes — improving them is
  optional unless the UI is extended to show them.
- No run-history/persistence exists (draftfantasy used Supabase; GAFFA has none).
