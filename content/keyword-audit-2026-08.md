## Recommendations, in order

1. **Submit `sitemap.xml` in Google Search Console.** It has never been
   submitted. Nothing else on this list matters until Google reads it.
   This must be done manually in the GSC UI — the Search Console API exposed
   through Windsor.ai is read-only.
2. Stop publishing role/term explainers. The category is saturated at 20/mo and
   forty of them already exist.
3. Concentrate internal links on the four Tier 1 pages.
4. Build the FM26 FAQ page from the KD-0 table above.
5. Retitle `gaffer-guide.html` around "gaffer in football / gaffer soccer" —
   the terms it already ranks for.
6. Grow referring domains from 37. At Authority Score 2 this is the binding
   constraint on every Tier 2 page, and no amount of additional content
   relieves it.
