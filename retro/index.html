Retro Player

A free, open-source Game Boy Advance emulator that runs entirely in your browser. Load a ROM file from your own device to play — nothing is uploaded anywhere.

Bring your own BIOS and ROM. Ball Knowledge does not host, link to, or distribute any BIOS or game files. You're responsible for only loading a BIOS and ROMs you legally own. Everything runs client-side — your files never leave your device.

Step 1 — load a BIOS file (gba_bios.bin) from your own console backup

Step 2 — load a .gba ROM file you own

How it works

Retro Player embeds IodineGBA, an open-source (MIT-licensed) Game Boy Advance emulator written in JavaScript. When you choose a ROM file, it's read straight off your device into memory using the browser's File API — it is never sent to any server. Saves are stored locally in your browser only.

Keyboard controls: Arrow keys (D-pad), X (A), Z (B), Enter (Start), Shift (Select), A/S (L/R shoulders). On mobile, use the on-screen pad below the screen.
